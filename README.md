# NONO Avatars

NONO 用户公开分享的演员头像库。不同用户维护的同名演员头像按“分享 1、分享 2、分享 3”等匿名编号分别保留，完全相同的图片复用同一文件。

## 使用

- 分享：在 NONO 的“数据源 → 本地头像分享”中确认后发布当前使用的头像，无需填写用户名。编号按首次成功分享的先后顺序自动分配，更新和撤回后再次分享保留原编号。
- 获取：在演员的头像选择中打开“神秘分享”，按匿名编号浏览并手动选择。
- 更新或撤回：在原 NONO 安装中更新、撤回自己的分享，无需用户提供 GitHub Token。

服务尚在接入中，初始索引为空。是否开放上传以 NONO 内实际状态为准。

## 公开范围

本仓库只保存匿名分享编号、演员姓名、标准化头像和必要的图片索引，不收集用户名、Emby 地址、对象编号、作品清单、登录信息或服务密钥。撤回后头像集合不再推荐，保留匿名编号占位以避免编号被复用。

分享前请确认你有权公开这些图片。图片相关权利归各自权利人所有。本仓库不对图片另行授予授权。

撤回会停止在共享索引中推荐自己的集合，不能收回他人已经下载的副本或 Git 历史中的内容。
